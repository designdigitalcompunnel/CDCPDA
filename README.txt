CDCPDA | TWO-PAGE RFP DESIGN CONCEPT

Extract the ZIP and open index.html in a current browser. Choose Rent Space
to open the second page. No build or server is required.

The original template's section order, card grids, image carousel,
tabs, accordion, and footer structure underpin the new design.

The Rent Space grid illustrates event setups. CDCPDA should confirm actual
rooms, capacities, amenities, availability, rates, and accessibility details.
The included planning guide was prepared for this concept. The tour link
opens an email draft addressed to CDCPDA. The rental form
demonstrates the interaction locally and neither sends nor stores entries.
Newsletter, event, and records requests open email drafts. Maps, giving
services, and optional web fonts need internet access.

The day/night and accessibility icons are decorative. See MEDIA_SOURCES.txt
for content and stock media sources.
